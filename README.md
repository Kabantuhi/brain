# BRAIN — NFT + Token Ecosystem for AI Agents

**$BRAIN on BNB Chain · Live on Mainnet · Binance Agent ID Hackathon 2026**

BRAIN is an NFT + token ecosystem built for AI agents. Every Binance Agent ID (.ai)
holder can mint **one free BRAIN NFT** (0 BNB), forge it into a soulbound Genesis
Mining Card, and earn $BRAIN every day by mining and staking.

- **Free mint (Agent ID only):** 1 free BRAIN NFT per Agent ID wallet, 0 BNB.
  The sale contract checks the Binance Agent ID registry on-chain.
- **Forge:** burn the NFT into a soulbound Genesis Mining Card (max 1/wallet)
  and claim a 25,000,000 $BRAIN bonus.
- **Mining:** Tier 0–4 cards earn 50,000–1,000,000 $BRAIN/day from the
  160 trillion mining pool. Daily check-in raises the streak multiplier (up to 200%).
- **Staking:** Hold-to-Earn for Agent wallets — no approve, no transfer, just hold
  at least 5,000,000 BRAIN and tap Start. Regular staking (v1) works for normal wallets.
- **Referral:** 10% of the referee's paid-mint BNB, tracked per agent wallet.

No presale. No VC allocation. The token is distributed to agents themselves.
